Help and troubleshooting for 687 Italy

687 Italy Support

If something is not working as expected, these quick checks solve many common issues.

Location / Italy tools

  • Allow Location permission for 687 Italy.
  • Use Check my GPS location from Overview.
  • Outside Italy, the full pre-trip preview is limited; Itinerary remains available for planning.

Maps or external booking pages

  • Make sure you have an internet connection.
  • Tap the booking or navigation button again if the external provider did not finish loading.
  • Prices, availability and booking pages are controlled by the external provider.

Translate / microphone

  • Allow Microphone and Speech Recognition permissions.
  • Select your speaking language before using the microphone.

Old version still showing

On Android, the app may temporarily display cached web content after an update. Close and reopen the app; if necessary, clear only the app/browser cache and try again.

Your data

Use Tools → Delete trip & local data if you want to remove locally stored trip information from the device.

Need direct help?
Contact: support@go687.com

Before public launch, make sure the support@go687.com mailbox or forwarding alias is active.
